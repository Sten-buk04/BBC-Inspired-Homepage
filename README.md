# BBC-Inspired-Homepage
Project Overview

This is a responsive BBC-inspired website built as a frontend practice project using HTML, CSS, and JavaScript. The goal was to strengthen my skills in responsive web design, Flexbox, media queries, and recreating real-world website layouts.

Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layouts, and responsiveness.
- JavaScript – Interactive website features.
- Flexbox – Responsive content arrangements.
- Media Queries – Screen adaptations at 600px, 900px, and 1280px.

Key Features

- Responsive design for mobile, tablet, and desktop screens.
- BBC-inspired navigation and homepage layout.
- Multiple content sections, including News, Sports, Entertainment, Health, and Lifestyle.
- Flexible news cards with images, headlines, and categories.
- Horizontal video carousels and interactive elements.
- Consistent styling, hover effects, and typography.

What I Learned

Through this project, I improved my understanding of:

- Building responsive layouts using CSS Flexbox.
- Working with multiple breakpoints and media queries.
- Structuring complex webpages with semantic HTML.
- Managing image sizes, spacing, and content alignment.
- Debugging CSS layout issues across different screen sizes.
- Translating existing website designs into functional frontend code.

Project Purpose

This project was created strictly for learning and portfolio purposes. It demonstrates my growing frontend development skills and ability to recreate complex, responsive website layouts.
